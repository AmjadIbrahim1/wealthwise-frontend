# 🚀 WEALTH-WISE (الحكمة المالية)

> Your intelligent financial companion for smarter investing, budgeting, and financial education (رفيقك الذكي لاستثمار أذكى وتنظيم ميزانية وتعليم مالي أحسن).

---

## Problem Statement (المشكلة)

In today's fast-paced financial world, individuals struggle with complex financial planning and investment decisions (النهارده في العالم المالي السريع، الناس بتعاني من تعقيد التخطيط المالي وقرارات الاستثمار). Traditional finance apps offer either basic rule-based insights or rely on slow AI models, resulting in delayed advice and missed opportunities (تطبيقات المالية التقليدية بتدي نصائح بسيطة أو بتعتمد على نماذج ذكاء اصطناعي بطيئة، فبتتأخر النصايح وتضيع الفرص). Users need real-time, personalized financial guidance that adapts to their unique goals and risk profiles (المستخدم محتاج إرشاد مالي فوري ومخصص يناسب أهدافه ودرجة تحمل المخاطرة بتاعته).

Wealth Wise addresses this by leveraging fast AI inference to deliver instant, intelligent financial advisory (ويث وايز بتحل المشكلة دي باستخدام ذكاء اصطناعي سريع لتقديم استشارات مالية ذكية فورية). With blazing-fast inference speeds and integrated mathematical analysis, we provide real-time, data-backed financial recommendations that transform how users manage their wealth (بسرعات استدلال عالية وتحليل رياضي مدمج، بنقدم توصيات مالية فورية مبنية على بيانات تغيّر طريقة الناس في إدارة ثروتها).

---

## 🎯 Objective (الهدف)

WealthWise is an AI-powered financial advisory and education platform that provides an intuitive, user-friendly interface for investment planning and financial analysis (ويث وايز منصة استشارات وتعليم مالية مدعومة بالذكاء الاصطناعي، بتقدم واجهة سهلة و intuitive للتخطيط الاستثماري والتحليل المالي). It offers an interactive AI chatbot, real-time market simulation, personalized insights, and comprehensive financial education resources, making financial literacy accessible to users of all levels (بتقدم شات بوت ذكي تفاعلي، محاكاة سوق فورية، توصيات مخصصة، ومصادر تعليم مالي شاملة، تخلّي الوعي المالي متاح لكل المستخدمين).

## 🧪 How to Run the Project (إزاي تشغّل المشروع)

### Requirements (المتطلبات):

- Node.js
- npm package manager (مدير الحزم npm)
- A web browser (متصفح ويب)

### Local Setup (الإعداد المحلي):

```bash
# Clone the repo (نزّل الريبو)
git clone <REPO_URL>

# Navigate to the project directory (ادخل فولدر المشروع)
cd psfront

# Install dependencies (نزّل الاعتماديات)
npm install

# Start development server (شغّل سيرفر التطوير)
npm start
```

The application will launch at http://localhost:3000 in your default browser (هتفتح التطبيق على http://localhost:3000 في المتصفح بتاعك).

### Environment Variables (متغيرات البيئة):

Create a `.env` file from `.env.example` (عمل ملف `.env` من `.env.example`):

```
REACT_APP_SUPABASE_URL=            # Supabase project URL (رابط مشروع Supabase)
REACT_APP_SUPABASE_ANON_KEY=       # Supabase anon key (مفتاح Supabase العام)
REACT_APP_BACKEND_URL=             # Backend API URL (رابط الـ API الخلفي)
REACT_APP_SECRET=                  # Encryption secret (سر التشفير)
REACT_APP_SITEKEY=                 # reCAPTCHA site key (مفتاح reCAPTCHA)
```
